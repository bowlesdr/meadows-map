# Meadows – Pods lots (web map)

Interactive map of the burial lot layout for the Meadows cemetery Pods area: pan and zoom over satellite imagery,
hover or tap a lot to see its side slope and stake-out tape readings, search by lot number or marker (e.g. `M109`).

Live map: https://bowlesdr.github.io/meadows-map/

This repository only holds the published map. It is generated by `tools/make_webmap.py` in the private
`meadows` project and updated with `tools/publish_webmap.bat`.
